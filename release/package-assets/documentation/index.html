The one rule you must not break

Every school must have its own separate database.
The control plane holds school and installation records only. It must never hold students, guardians, staff, attendance, results or fee data. If anyone offers you a “shared table with a tenant ID” version of this product, it is not this product — do not accept it.

What is included

  • Super Admin control plane (schools, installations, commercial records, provisioning)
  • Per-school dedicated database with its own schema
  • First-run web installer with server preflight and automatic migrations
  • CodeIgniter Shield authentication (users, groups, sessions, login throttling)
  • Role filters for Super Admin and school-level access control
  • Health endpoint for monitoring

What is NOT included in this version

  • SMS notifications
  • Online payment gateway
  • Unofficial / QR WhatsApp Web automation
  • Automated WhatsApp Business API
  • Native app-store packaging (iOS / Android)

These are deliberate product decisions, not missing files.
